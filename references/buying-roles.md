什么时候读这个文件：第 2–3 步，要决定在客户公司里先找哪些部门和职位、找到的人怎么排序、搜索词怎么写时。这里的角色分析只在内部用，不直接写给用户。

# 采购链路、职位名称与搜索词

这里的职位和部门叫法是按常见情况整理的经验知识，不是某家公司的真实架构。每家公司叫法不同：有联网搜索时，按 `web-research.md` 去确认；没有时，在搜索口令后注明"按同类公司常见情况给出"，请用户把他看到的叫法发过来。

## 1. 四个角色怎么分

| 角色 | 怎么判断 | 他最关心 | 怎么用他 |
|---|---|---|---|
| 拍板人 | 对这笔预算和结果负责，最后签字或在会上拍板 | 业务结果、风险、同行在做什么、投入产出 | 带着具体方案、最好经人引荐去见；话少、给结论 |
| 使用者 | 每天用你的产品，或者为这个问题背指标 | 少加班、少出错、好上手、不添麻烦 | 第一批接触对象：最容易聊起来，能告诉你真实痛点，也会在内部替你说话 |
| 把关人 | 采购、IT/信息安全、法务、财务、合规 | 资质、安全、合同条款、价格、流程 | 不要从他们切入；在业务侧有进展后，提前了解准入流程和标准 |
| 影响者 | 技术骨干、项目经理、拍板人身边信任的人 | 技术细节、在内部有面子、学到东西 | 请教他的专业意见；他能告诉你决策流程和预算节点 |

同一个人可能身兼两角，小公司尤其如此，老板常常既是拍板人又是使用者。

## 2. 谁拍板：看四件事

1. **金额相对客户的规模**：同样一笔钱，对大集团可能是部门负责人就能批的预算，对小公司就要老板点头。
2. **影响范围**：只影响一个部门，部门负责人通常能定；跨部门或碰到核心业务，就要分管副总甚至一把手。
3. **单位性质**：国企、银行、医院、政府、学校，通常有招投标和集体决策。这时"拍板"是一套流程，不是一个人：要找的是推动立项的人，并弄清流程。
4. **新上还是替换**：替换现有供应商时，现有系统的负责人是关键影响者，也可能是最大的阻力，要尽早了解他的顾虑。

拿不准时问用户一句："你们以往成交的同类客户，最后是谁签字的？"用户的成交经验比任何通用规律都准。

## 3. 公司类型：职位和部门的常见叫法

| 公司类型 | 拍板层常见叫法 | 部门负责人常见叫法 | 注意 |
|---|---|---|---|
| 互联网、科技公司 | CEO、业务线负责人、VP、CTO | 负责人、总监、Head、leader | 同一职能常分散在各业务线，按"业务线 + 职能"搜比只按部门搜准；头衔不统一，看"负责什么"比看头衔可靠 |
| 央企、国企 | 董事长、总经理、分管副总经理；部分集团设首席数字官、首席信息官 | 部长、副部长、主任、处长、经理 | 信息化部门常叫"数字化部""信息化部""科技信息部""信息中心"；采购多走招投标，二级单位也有自己的预算 |
| 银行 | 行长、分管科技的副行长、首席信息官 | 总行部门总经理、副总经理、处长、团队负责人；分行行长、副行长、部门总经理 | 系统类采购多在总行；分行能决定的范围有限，但分行的人可以帮你了解总行 |
| 证券、基金、保险 | 总经理（总裁）、分管副总、首席信息官 | 信息技术部、金融科技部、信息技术中心的总经理或总监 | 金融机构的科技负责人换得勤（见第 7 节），有联网时用新闻确认现在的岗位设置 |
| 外企 | Country Manager、General Manager、VP | Director、Head of、Manager，区域职位常带 China、Greater China、APAC | 中英文各搜一次；不少决策在区域总部或全球总部，中国区负责人是关键影响者 |
| 民营制造 | 老板、总经理、生产副总 | 厂长、部门经理、主管、工程师 | 中小型企业老板常亲自拍板；设备、工艺类产品要找车间和技术的人 |
| 中小企业、连锁门店 | 创始人、老板、总经理 | 运营总监、营运经理、区域经理、店长 | 层级少，直接找老板最快；连锁品牌的总部运营是关键使用者 |
| 医院 | 院长、分管副院长；重大采购通常经集体决策和招标 | 临床科室主任、医学装备部（设备科）主任、信息中心（信息科）主任 | 合规要求严，话术里不出现任何利益暗示；先找使用科室和信息科了解需求和流程 |
| 学校、政府、事业单位 | 校长、局长、分管领导 | 处长、科长、主任；信息中心、网络中心 | 采购走政府采购流程；以交流、试点、案例分享切入，不催单 |

## 4. 产品类型：该找谁

每类给出四个角色的常见职位和搜索词示例。搜索词里的"XX"换成目标公司名或品牌名。

**4.1 通用企业软件、SaaS（协同办公、ERP、低代码等）**
- 拍板人：CIO、信息化负责人、分管副总；中小企业是老板或总经理
- 使用者：各业务部门负责人和骨干
- 把关人：IT 架构、信息安全、采购、财务、法务
- 影响者：IT 经理、系统管理员、业务部门里最懂系统的人
- 搜索词：「XX 信息部 总监」「XX 数字化 负责人」「XX IT 经理」

**4.2 人力资源类（HR SaaS、招聘服务、培训课程、测评）**
- 拍板人：CHO、人力资源 VP、人力资源总监（HRD）
- 使用者：招聘负责人、培训或人才发展负责人、薪酬绩效负责人、HRBP
- 把关人：IT 和信息安全（员工数据）、采购、财务
- 影响者：HR 经理、人力资源共享中心负责人、组织发展专家
- 搜索词：「XX 人力资源 总监」「XX 人才发展 负责人」「XX 招聘 负责人」；企业大学型公司加「XX 大学」

**4.3 财务类（费控、税务、资金、财务共享）**
- 拍板人：CFO、财务总监
- 使用者：财务共享中心负责人、费用会计、税务经理、资金经理
- 把关人：IT、审计或内控、采购
- 影响者：财务 BP、财务经理
- 搜索词：「XX 财务共享 负责人」「XX 税务 经理」「XX 财务 总监」

**4.4 营销类（广告投放、内容服务、营销技术、会员 CRM）**
- 拍板人：CMO、市场 VP、品牌总监；电商型公司是电商负责人或增长负责人
- 使用者：品牌、数字营销、内容、电商运营、会员运营的负责人
- 把关人：市场采购、法务（广告合规）、财务
- 影响者：投放经理、市场经理、负责对接代理商的人
- 搜索词：「XX 品牌 总监」「XX 数字营销 负责人」「XX 电商 运营总监」

**4.5 销售类工具（CRM、销售赋能、渠道管理）**
- 拍板人：销售 VP、营销中心总经理、CSO
- 使用者：销售运营负责人、区域销售经理、客服负责人
- 把关人：IT、采购、财务
- 影响者：销售运营经理、CRM 管理员
- 搜索词：「XX 销售运营」「XX 营销中心 总经理」「XX 大客户部 总监」

**4.6 云、IT 基础设施、算力、网络**
- 拍板人：CIO、CTO、基础架构负责人
- 使用者：运维、基础架构、研发团队
- 把关人：采购、信息安全、财务
- 影响者：架构师、运维经理、SRE 负责人
- 搜索词：「XX 基础架构 负责人」「XX 运维 总监」「XX 架构师」

**4.7 网络与数据安全**
- 拍板人：CISO、信息安全负责人、CIO；金融机构常是首席信息官或分管科技的领导
- 使用者：安全运营、安全工程师
- 把关人：合规、风控、审计、采购
- 影响者：安全架构师、安全团队骨干
- 搜索词：「XX 信息安全 负责人」「XX 安全 总监」「XX 数据安全」

**4.8 数据、AI 应用**
- 拍板人：提出需求的业务负责人 + CIO、CDO（首席数据官）或 CTO
- 使用者：业务部门、数据团队
- 把关人：IT、信息安全、合规（数据合规）
- 影响者：数据平台负责人、算法负责人、业务分析师
- 搜索词：「XX 数据中台 负责人」「XX AI 负责人」「XX 大模型 应用」

**4.9 工业软件、自动化、检测设备（MES、视觉检测、产线设备）**
- 拍板人：生产副总、制造总监、厂长；集团型企业还有数字化部或智能制造部
- 使用者：车间、工艺、设备、质量部门
- 把关人：采购、IT（系统类产品）、财务、EHS
- 影响者：工艺工程师、设备工程师、IE 工程师
- 搜索词：「XX 智能制造 负责人」「XX 设备部 经理」「XX 工艺 工程师」

**4.10 原材料、零部件、工业品**
- 拍板人：采购总监、供应链总监；新品选型时研发负责人分量很重
- 使用者：研发、工程、生产
- 把关人：质量（供应商质量工程师 SQE、供应商准入）、采购、财务
- 影响者：研发工程师、SQE
- 搜索词：「XX 采购 总监」「XX SQE」「XX 研发 结构工程师」

**4.11 物流、供应链服务**
- 拍板人：供应链 VP、物流总监
- 使用者：仓储、运输、计划部门
- 把关人：采购、财务、法务
- 影响者：物流经理、仓库经理、计划经理
- 搜索词：「XX 物流 总监」「XX 供应链 负责人」「XX 仓储 经理」

**4.12 行政、福利、办公、差旅**
- 拍板人：行政总监、人力资源总监；差旅常是 CFO
- 使用者：行政经理、全体员工
- 把关人：采购、财务
- 影响者：行政专员、工会（员工福利）
- 搜索词：「XX 行政 总监」「XX 行政 经理」「XX 差旅」

**4.13 门店类产品（收银、会员、排班、门店设备），卖给连锁品牌**
- 拍板人：创始人、老板、总经理
- 使用者：运营总监、区域经理、店长、财务
- 把关人：财务（小公司常由老板兼任）
- 影响者：运营经理、IT 负责人、店长
- 搜索词：「XX品牌 运营总监」「XX品牌 创始人」；打一类品牌用「连锁餐饮 运营总监 城市名」

**4.14 医疗器械、医院信息化**
- 拍板人：院长、分管副院长；重大采购经集体决策和招标
- 使用者：临床科室主任和骨干、信息科
- 把关人：医学装备部（设备科）、采购办、纪检监察
- 影响者：科室骨干、设备工程师、信息科工程师
- 搜索词：「XX医院 信息中心 主任」「XX医院 设备科」「XX医院 科室名 主任」
- 提醒：这个领域对商业贿赂查得严，话术只谈临床需求、产品和案例

**4.15 专业服务（咨询、培训、律所、审计、猎头）**
- 拍板人：对应职能的最高负责人，例如法务总监（律所）、CFO（审计、税务）、HRD（猎头、培训）、战略负责人（咨询）
- 使用者：对应职能的经理
- 把关人：采购、法务
- 影响者：职能骨干、总裁办或战略部
- 搜索词：「XX 法务 总监」「XX 战略 负责人」「XX 人力资源 总监」

## 5. 搜索词怎么写

**公式**：公司 + 部门/业务线 + 职位关键词，2–4 个词。

**部门同义词**（第一个搜不到就换下一个）：

| 职能 | 常见叫法 |
|---|---|
| IT、数字化 | 信息部、信息技术部、IT 部、信息中心、数字化部、流程与 IT、科技部、金融科技部、信息科技部、智能制造部 |
| 信息安全 | 信息安全部、网络安全、安全中心、安全合规 |
| 数据、AI | 数据管理部、数据中台、大数据中心、AI 中心、算法 |
| 采购 | 采购部、采购中心、集中采购、招标采购、供应链管理部、寻源 |
| 人力 | 人力资源部、HR、组织发展、人才发展、企业大学、HRBP |
| 财务 | 财务部、财务共享中心、资金部、税务、预算 |
| 市场 | 市场部、品牌部、数字营销、增长、用户运营、会员 |
| 销售 | 销售部、营销中心、大客户部、渠道部、区域销售 |
| 生产制造 | 生产部、制造部、工厂、设备部、工程部、工艺部、质量部、EHS |
| 研发 | 研发中心、研究院、技术中心、产品部 |
| 行政 | 行政部、综合管理部、办公室 |
| 法务合规 | 法务部、法律合规部、风控、内控、审计 |
| 供应链、物流 | 供应链、物流部、仓储、计划部 |
| 连锁运营 | 运营部、营运部、门店运营、拓展部、加盟 |

**职位关键词**：先用"负责人""总监""总经理"找到管理层；人太少就降一级用"经理""主管"；找影响者用"架构师""工程师""专家"。外企加英文：Director、Head、Manager。

**几种情况**：
- 大集团：用事业部或子公司名代替集团名。例如卖楼宇设备，搜某家电集团旗下的楼宇事业部，而不是集团名。只搜集团名，人太多翻不到。
- 分支机构：公司 + 城市 + 部门，例如「XX银行 杭州分行 科技」。
- 一类公司：行业词 + 职位 + 城市，例如「连锁餐饮 运营总监 上海」「动力电池 采购总监」。
- 外企：中文、英文各一个，例如「XX 信息技术 总监」「XX IT Director」。

**好词和坏词**：
- 好：「XX 信息部 总监」：公司、部门、层级都有，搜出来的人少而准。
- 太泛：「XX」：几千人，没法挑。
- 太多：「XX 信息部 总监 数字化 采购 负责人」：关键词互相打架，容易什么都搜不到。
- 不允许：任何带手机、电话、邮箱、微信的搜索词。

每个搜索词后面配半句理由，例如"银行的 IT 部门多叫信息技术部"，用户才知道搜不到时该往哪个方向换。

## 6. 找合作资源、找内推、找人请教

同一套"找对的人 → 找引荐 → 站内联系"的方法，也适用于：
- **战略合作、商务拓展**：找对方的商务拓展（BD）负责人、战略合作负责人。搜索词：「XX 商务拓展」「XX 战略合作 负责人」。
- **招渠道、代理商**：找目标区域经销商的老板或渠道负责人。搜索词：「地区 + 行业 + 代理/经销 + 总经理」。
- **市场合作、异业合作**：找品牌合作、市场合作、商务拓展（BD）负责人。搜索词：「XX 品牌合作」「XX 商务拓展 负责人」。
- **找投资人**：按赛道找投资经理、投资总监、合伙人。搜索词：「机构名 投资 赛道词」。投资圈尤其看重熟人引荐，先看共同好友。
- **求职、找内推**：找用人团队的负责人、做同一岗位的人、HR 或招聘负责人，优先校友和前同事。搜索词：「公司 业务线 岗位」「公司 业务线 负责人」「公司 招聘」。同岗位的人最清楚真实的工作内容，也最可能帮忙内推。
- **职场问题，找过来人请教**：找经历过同样处境的人。例如想从运营转产品，就找已经从运营转过去的产品经理。搜索词：「目标行业或公司 目标岗位」，点开主页看经历里有没有同样的转变。
